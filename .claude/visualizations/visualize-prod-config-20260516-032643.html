What changed from v18

The dedicated BT_CLR key at the top-left of the Func layer replaces the old BT_SEL 0 + BT_SEL 1 combo, which was confusing — the combo name implied "clear profiles 0+1" but actually cleared the currently active profile. The combo has been removed entirely.

Layer 3 — Num (numpad)

Reached by holding the right outer thumb. Tap the same thumb instead to make it sticky — useful for typing one or two digits without a long hold. The right half forms a real 10-key numpad; the left half just exposes the top number row again for muscle-memory continuity. The left outer thumb is now the gateway to Func.

Build & deploy

GitHub Actions pipeline

Every push triggers .github/workflows/build.yml, which uses ZMK's standard build action driven by build.yaml. Two firmware artifacts are produced per run:

  • corne_left.uf2
  • corne_right.uf2

Board identifier

The board name is nice_nano//zmk — the //zmk suffix has been required since ZMK's Zephyr 4.1 update in December 2025. Older configs that still use nice_nano alone will fail to build.

Versioning convention (from CLAUDE.md)

  • Active build file: config/corne.keymap — always an exact copy of the current prod version (not a symlink — symlinks have historically caused issues here).
  • Version files live alongside it: config/corne_prod_vN.keymap.
  • Each version has a matching config/corne_prod_vN_keymap_guide.tex with a compiled PDF. Compile with pdflatex -interaction=nonstopmode <file>.tex — twice, so the TOC resolves.
